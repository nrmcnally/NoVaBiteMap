# Data licensing and attribution

- Virginia DWR ArcGIS services are agency data. Preserve DWR attribution,
  dataset-specific use notes, update dates, and the original service URL.
- USGS-authored data and information are generally public domain; individual
  releases still retain their DOI, authors, version, and citation. Aquatic GAP
  v2.0 is marked CC0 by USGS.
- National Weather Service data is U.S. government information. API clients
  must identify themselves with a meaningful user agent and should respect
  service limits.
- EPA datasets retain their provider, method, station, characteristic, result
  qualifiers, and dataset-specific citation.
- OpenStreetMap tiles require OpenStreetMap contributor attribution and must
  comply with the tile usage policy. Production scale should use an appropriate
  hosted tile provider rather than relying on the community tile server.

This repository does not relicense upstream data. Check each official source
before redistribution, preserve its provenance, and update these notes when a
provider changes its terms.
