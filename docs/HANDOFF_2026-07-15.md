# BiteMap NOVA handoff — 2026-07-15

## Current objective

Prepare the existing app for a small closed alpha. The most recent sprint removed
the main runtime split between the map's bundled scores and the FastAPI/PostgreSQL
scoring backend. Do not start another data-research or design expansion before the
Docker smoke test and alpha journeys below are complete.

## Completed in the latest sprint

- Added `GET /api/explore`, a single canonical database payload containing all
  public locations, the 20 reviewed target species, full access/advisory context,
  and per-species scores from the same engine used by location details.
- Explore now server-loads that canonical payload. If the API is deliberately
  unavailable, it falls back to the checked-in evidence snapshot rather than
  inventing or partially mixing data.
- Canonical rows are never rescored in the browser. A missing API opportunity now
  means the species failed the backend evidence gate.
- Location pages prefer the canonical database record and fall back safely.
- My Spots uses the same canonical locations and scores when the API-backed account
  stack is active.
- The API-backed favorite route delegates location/species validation to FastAPI,
  preventing the web seed from rejecting a valid database record.
- The Vite 8 development overlay loop was fixed by disabling its fragile console
  forwarding while preserving normal live reload.
- The Fish Guide has 37 family-grouped species, researched profiles, credited local
  images, and improved non-specimen artwork for white perch, gizzard shad, creek
  chub, and longnose dace.
